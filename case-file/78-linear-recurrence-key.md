# 78 — Linear-recurrence key mod 26 (cycle 80)

> *Gromark's digit-man had a cousin who never went to school in base ten. He adds the last few key letters with his own weights, plus a constant, and keeps going.*

## Family (new)
Key generated by an **affine linear recurrence over Z₂₆**, the base-26 generalisation of Gromark's lagged Fibonacci:

    k[i] = c₁·k[i−1] + … + c_L·k[i−L] + d   (mod 26)

with **arbitrary** coefficients c₁…c_L and constant d, any seed. Special cases: Caesar (L 1, c 1, d 0), progressive key (c 1, d ≠ 0), any periodic key of period ≤ L, the Fibonacci key k[i] = k[i−1] + k[i−2] seeded from a keyword. Gromark (cycles 10–11, 65) only covered base 10 with unit coefficients; this mod-26 family with free weights was not in the coverage table.

Substitution: KA or A–Z tableau, Vigenère (k = c − p) or Beaufort (k = c + p); variant Beaufort is Vigenère negated, which maps the family onto itself (c same, d → −d).

## Test (exact, no English scoring)
Key indexed by plaintext position (model A: substitute, then transpose). The 13 key values under EASTNORTHEAST (21–33) fix d from the first equation and must satisfy every remaining recurrence equation inside the block; the key is then propagated through 34–62 and must reproduce all **11** key values under BERLINCLOCK (63–73). Every (c₁…c_L) is enumerated.

- **Direct:** L 1–6 (1.29 × 10⁹ tests per text).
- **Behind 165,065 transpositions** (the cycle 13/22 set, identity first): L 1–3 (1.21 × 10¹⁰ tests per text).

## Verdict
**Negative.** Any mod-26 affine linear-recurrence key of order ≤ 6 directly on the copper, and of order ≤ 3 behind the 165,065-transposition set, is excluded under KA/A–Z Vigenère/Beaufort/variant. The test has full power (false-positive rate ≈ 26^(L+1−22) per configuration; nulls give 0, controls 5/5).
