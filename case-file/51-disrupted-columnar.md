# Case file 51 — Disrupted (triangular) columnar, exact (cycle 53)

**Why this family.** The coverage table has carried "Disrupted columnar: exact test; audit cycle 5" as owed since
cycle 5, which only annealed one disruption rule with modest power. Disrupted columnar is the classic way to make a
keyed columnar look irregular while staying keyword-driven, which fits the K1–K3 style profile (case file 10): a word
key, a grid, and a trick that hides the grid. This cycle tests it exactly.

**Model.** Grid width w = keyword length, ⌈97/w⌉ rows, cells with row-major index ≥ 97 unused. Disruption areas
start in row 0 at the column ranked 1 by the key; the next area starts on the row after the previous one ends, at the
column ranked 2, and so on cyclically until the rows run out. Two shapes, because published descriptions differ:
- **T1** (ACA-style shrinking triangle): the area covers columns c…w−1 in its first row, c+1…w−1 in the next, until
  the right edge.
- **T2** (growing triangle): row t of the area covers columns c…c+t, ending when it reaches the right edge.

Plaintext fills the undisrupted cells row by row, then the disrupted cells row by row; ciphertext = columns read top
down in key-rank order. These are my readings of the rule (labelled as such); other conventions (areas starting in
the key's column numbered 1 on the *last* row, left-pointing triangles) are not covered.

**Search space.** Column orders: cycle 52's 1,837 keyword orders (106 themed words + 3,000 frequent English words,
widths 4–14) plus **every** order of widths 3–7 → 13,572 distinct disrupted permutations (T1 and T2). The 92 themed
orders' disrupted permutations were also composed with every one of the 1,837 keyword plain columnars, in both layer
orders (K3-style double). Total **689,588 permutations**, each with its inverse, × periodic or progressive keyword key
(k[i mod L] + s·⌊i/L⌋, L 1–22, s 0–25), Vigenère/Beaufort, A–Z/KRYPTOS tableau, key indexed by plaintext or by carved
position: **6.31 × 10⁹ exact tests per text** against the 24 official crib letters. The checker is copied verbatim
from cycle 52 (`dcol.c`).

Tools: [`tools/disr_gen.py`](../tools/disr_gen.py), [`tools/disr.c`](../tools/disr.c),
[`tools/ctl53.py`](../tools/ctl53.py), [`tools/run_cycle53.sh`](../tools/run_cycle53.sh). Raw output in
[`data/cycle53/`](../data/cycle53/) (`dperms.txt` is regenerated by `python3 disr_gen.py 92` from cycle 52's
`orders.txt`).

## Result
| Text | Consistent L ≤ 20 | L = 21 | L = 22 |
|---|---|---|---|
| **K4** | **0** | 2 | 10 |
| shuffled null 0 | 0 | 1 | 23 |
| shuffled null 1 | 0 | 2 | 20 |

K4's two L = 21 fits (free letters filled by quadgram hill-climb) score −6.97 and −7.27 per quadgram (planted English
−4.09) and read as noise: `GZJQINOUIFAXPSHHSVJMX…`, `PVTBRXCHQVPUGMUQRHHTZ…`. L ≥ 21 sits at the null level, as
expected when a 21-letter key has almost as many free letters as there are crib constraints.

**Verdict: negative** for keyword-driven and all width ≤ 7 disrupted columnar (T1/T2), alone or doubled with a themed
keyword columnar, under periodic/progressive keys up to L = 20. Open: other disruption conventions, arbitrary orders
of width ≥ 8, running keys or mixed alphabets on top.
