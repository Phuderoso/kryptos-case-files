# Cycle 180 tools (IDEAS I-142): linear-recurrence key over keyed (Quagmire) alphabets behind K3-law decimations / routes

- `PREREG180.md` — pre-registration (pushed before any K4 / registered-null run).
- `lrk180.c` — exact solver. `gcc -O3 -march=native -fopenmp -o lrk180 lrk180.c` (needs BMI2 for `_pext_u64`).
  `lrk180 CT perms.bin alphafile label qlo qhi mode Lmin Lmax`; mode 0 = key on the plaintext index (L ≤ 8), mode 1 = key on the
  carved index (L ≤ 4). Output `H` (per L × type × form: perms, (alphabet, type) pairs, mod-2 passes, fits), `M` (fits with the
  mod-2 / mod-13 solution lists), `O` (overflow), `X` (table/solve0 disagreement, must never appear), `END`.
- Alphabet files: `alpha172.txt` is regenerated by `python3 ../cycle172/mkalpha172.py ../../data/cycle158/vocabulary_all.txt`
  (18,776 lines, md5 92793b74…); `alpha_themed180.txt` = the same script on `../cycle178/seeds178.txt` (144); `alpha_recount180.txt` (33).
- `run_cycle180.sh` (main run, resumable), `nulls180.txt` (seeds 18011–18029), `summarize180.py` (cells, labels, grid).
- `plant180.py`, `run_controls180.sh`, `checkctl180.py` — planted controls; `decode180.py` — independent string-level replay + score.
- `mkslice180.py`, `recount180.py`, `cmprecount180.py` — independent numpy brute-force recount on a slice and comparison.
- Support: `all.bin` (165,782 K3-law decimations / routes, md5 946402ca…), `all_s8.bin` (= all.bin[::8], md5 3dd34d3c…), `quadgrams.json`.
