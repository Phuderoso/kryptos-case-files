## Model (frozen; group arithmetic, scopes and crib seats exactly as PREREG242)
Plain alphabet X, cipher alphabet Y; cell = index in the alphabet (0–25), cell 26 = the extra symbol (never carved). Forms **V** c = p ⊕ k, **R** c = p ⊖ k, **B** c = k ⊖ p in g0 or g1. The 24 crib seats (EASTNORTHEAST 1-indexed 22–34 = 0-based 21–33, BERLINCLOCK 64–74 = 63–73) give 24 required key cells k_j. A running key is a stream of **letters**; letter → cell by map **M**: 0 = index in X, 1 = index in Y, 2 = index in A–Z (a map equal as a permutation to an earlier one is skipped: S1 keeps M 0 and 2). Required key letter at seat j = M-alphabet[k_j]; a seat with k_j = 26 cannot be met by a letter key (counts as a mismatch). Key letter at plaintext position i = T[(o + i) mod |T|]. Direct (no transposition).

- **C130 rule (adopted, Voynich):** each one-error plant is classed PENDANT / TIE / MAJ. In this model every crib seat is pinned by exactly one key-text letter, so a wrong carved letter always shows as one identified mismatched seat: every one-error plant is **MAJ by construction**; PENDANT and TIE cannot occur, so the "draw ≥ 1 pendant and ≥ 1 tie" clause is structurally N/A.
