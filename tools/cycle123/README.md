# tools/cycle123 — Cadenus-style rotated columns + periodic key; bank-frame audit

- `cadenus.c` — exact crib test. Width w (ragged, 97 letters), column order π, **arbitrary per-column rotation** s_c, read by rows (Cadenus, holes skipped) or by columns; both directions (plaintext or ciphertext written into the grid); then a periodic key p 1–20 on A–Z or KRYPTOS tableau, Vigenère or Beaufort (variant = Vigenère consistency), key indexed by plaintext (model A) or carved (model B) position. Backtracking over columns; the cribs EASTNORTHEAST (0-based 21–33) and BERLINCLOCK (63–73) touch every column for w ≤ 13, so every rotation is constrained. Survivors are fully decrypted and quadgram-scored.
- `gen_orders.py` — all column orders w 2–7, keyword orders w 8–13 (cycle-52 THEMED list + clock/rotation words + cycle-56 vocabulary, stable ties). All 40,320 orders of w 8 are generated by `run_cycle123.sh`.
- `plant.py` — independent Python reference encryptor (positive controls) + shuffled-K4 nulls (seeds 12301–12305).
- `frame_audit.py` — looks up textbook keyword-columnar σ and σ⁻¹ (built by `plant.py`) in the 165,065-transposition bank `perms97.bin`.
- `run_cycle123.sh` — full reproduction (≈ 2 min for p ≤ 13; the p 14–20 pass is capped at 300 s).
