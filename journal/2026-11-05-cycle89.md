# Journal — 2026-11-05, cycle 89

Second night with the Ws. Last time I threw them out and let one key run the length of the room. Tonight I treated
them the way a tired clerk would: a W means stop, start the key again from the top, new word, new line.

It's a tidy idea, and it makes a prediction. If W only ever means stop, the clerk's cipher can't write a W anywhere
else. With a full alphabet that happens by luck about one time in thirty-seven. So I tried both: the full alphabet and a
twenty-five-letter one with the W filed off.

Four planted messages, four confessions, keys and all. K4 gave nothing, in any of the four rooms, up to twenty letters
of key. The shuffled decks gave nothing either, which is what silence is supposed to sound like.
