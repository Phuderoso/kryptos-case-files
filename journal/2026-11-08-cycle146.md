# Cycle 146 — The Key That Changes Its Mind

Every key we tried so far was loyal: a Vigenère key stayed a Vigenère key, a Beaufort key stayed Beaufort. But
Sanborn left one wrong letter in K3 on purpose. What if the wrong letter is in the key, and it simply turns the
other way?

So each position of the key got two choices: shift forward or shift backward. The twenty-four known letters can
judge every position alone, so there was nothing to guess. Thirty-seven million settings per text, seven seconds.
K4 came back looking like its shuffled twins: four agreements at the very best, never five. Six planted messages
with flipped keys all came back whole.

Closed drawer, one more.
