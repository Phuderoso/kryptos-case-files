# Cycle 198 — One Letter Missing, One Letter Lying (2026-11-10, ~03:41–04:25 PT)

Last night's suspect had a letter fall off the copper. Tonight I asked the obvious follow-up: what if one of the clue letters is lying too?
K1–K3 have both kinds of mistake. Case 184 forgave the first and trusted every crib letter. One bad letter in the wrong place can kill a true
fit, so the exclusion needed a second look.

**The tool.** `cmp198`. For every crib record and every period pair it finds the loops in the crib graph. A config that fails in exactly
one loop gets a second chance: every distinct way of dropping one crib letter from that loop is tried. Each config carries a chance bound U,
a union bound, so it can only overstate the odds. Before registration it matched `cmp197` cell for cell on the strict counts.
