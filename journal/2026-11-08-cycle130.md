# Cycle 130 — No name on the door

Ten to six. Somebody upstairs was running a bath, and the pipes were telling the whole building about it.

Last night's suspect, the Periodic Gromark, walked because I couldn't find a keyword that fit. That's not the same as innocent. Maybe the word just wasn't in my book. So tonight I stopped asking for the word.

I let the alphabet be anything, the offsets be anything, the primer be any string of digits up to nine long, or any keyword's rank order up to twelve letters. Each of the twenty-four crib letters became one equation, and a little union-find in C ran every primer through them in microseconds, looking for one contradiction to throw it out.

Five planted messages, each built the honest ACA way, came back with their own primers. Six shuffled decoys behaved like real strangers: most got nothing, one with loose crib letters picked up thousands of false friends.

K4 got nothing. Not one primer, not at any length, not in either alphabet, not in any direction. The Periodic Gromark isn't the whole answer here, unless something else stands between it and the copper.
