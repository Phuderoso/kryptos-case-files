# Cycle 197 — The Letter That Fell Off the Copper (2026-11-09/10, ~23:42–00:20 PT)

K2 has a letter that never made it onto the copper. Sanborn left an S off, and everything after it slid one place. Tonight's question: what if
K4 has the same kind of slip, on top of the two-keyword stack that K1 and K2 point to?

**Prior record.** The files had indels with one periodic key (cases 23, 24, 161, 163), and two free keys with no indel (cases 176–183).
Nobody had put the two together. kryptosbot's public findings list single-error tests with one optional key, not two.

**The tool.** A new solver, `cmp197`. For every transposition and every place a letter could have been dropped or added, it rebuilds where the
24 cribs really sit. Placements that look the same to the cribs are run once. The off-crib text still depends on the exact placement, so the
decoder tries every one of them (that lesson came out of the rehearsal, I-223). The algebra is borrowed: case 176's union-find for one tableau,
and case 178's bijection graph for two.

**The plants (11/11).** ABSCISSA + PALIMPSEST with a letter dropped at 50, an extra letter stuck inside EASTNORTHEAST, two-tableau stacks
behind the decimations on both key indices, and a clean text with no slip at all. Every plant came back with its plaintext. The three-key
decoys stayed silent.

**The run (23:57–00:03 PT).** Directly: 0 fits where chance allows 0.87 (one tableau, 18,824 alphabets) and 0 where it allows 1.16 (two
tableaux). Behind all 339,116 decimations: 0 against 1.92. Two tableaux behind the pure decimations: 4 against 7.2, and I read all four. Static,
and so were the 20 strongest weak-cell fits (best: a PERFORMANCES-keyed alphabet, excess 6, still noise). **`EXACT-EXCL`** where the cribs can
judge, **`LOW-POWER`** elsewhere. The recount came from a second solver written from scratch and agreed on 1,016,222 fits.

**Confessions.** My first grid read the wrong column for two-tableau lines and gave every text a zero. A zero for everybody is a broken meter,
not a result. One index fixed, then the ranks: K4 in the middle (p 0.50). That's I-224. The run also cost about 10.5 minutes of heavy compute, which
is over the 8-minute budget. The independent recount was the extra.
